# VERCUNO Website — Product Requirements Document

Version: 1.0
Status: Active foundation
Project: VERCUNO Official Website

## 1. Product Vision

VERCUNO is an independent software and AI studio.

Tagline: Digital, Built Better.

The website must establish VERCUNO as a premium
technology studio and convert visitors into qualified
project inquiries.

## 2. Target Audience

- Business owners
- Startup founders
- Companies needing custom digital solutions
- Agencies seeking technical partners

Primary market: Indonesia
Secondary market: International

Website language: English.

## 3. Core Services

- Web Development
- Custom Web Applications
- AI and Workflow Automation
- Technical Maintenance and Support

Pricing is custom and determined after project discovery.
Do not display fixed pricing packages.

## 4. Primary Goals

1. Establish professional credibility.
2. Demonstrate design and engineering quality.
3. Showcase verified founder projects.
4. Explain services clearly.
5. Generate qualified project inquiries.

## 5. Website Architecture

Homepage sections:

1. Hero
2. Selected Work
3. Services
4. About
5. Process
6. Contact
7. Footer

Additional pages:

- /work
- /work/[slug]
- /contact
- /privacy when collecting personal information

Build one section at a time.

## 6. Initial Portfolio

WORLD//ONE — Web Development
VETO — Blockchain Web Application
AI Content Studio — AI Workflow

These are Founder Projects, not paid client projects.

All descriptions must be verified against actual work.
Never invent customers, testimonials, awards, or results.

## 7. Conversion

Primary CTA: Start a Project
Secondary CTA: Explore Work

Business email: vercuno.studio@gmail.com

The contact experience must be clear and functional.
Never publish a fake contact form or broken CTA.

## 8. Technical Direction

Preferred stack:

- Next.js
- TypeScript
- Tailwind CSS
- GSAP or Motion when justified
- Vercel hosting

Optimize for maintainability and performance.

## 9. Quality Requirements

- Responsive across desktop, tablet, and mobile
- Accessible semantic HTML
- Keyboard navigation
- Reduced-motion support
- Fast page loading
- Optimized images and media
- No horizontal overflow
- Secure contact form handling
- SEO metadata and semantic structure

Target Lighthouse performance: 90+
Target Lighthouse accessibility: 95+

These are goals, not guaranteed scores.

## 10. Out of Scope for Initial MVP

- Client dashboard
- Authentication
- Payment processing
- E-commerce
- Full AI chatbot
- Large WebGL experiences
- Heavy mascot animations

## 11. Development Approach

Section-by-section development:

1. Define section requirements.
2. Approve visual direction.
3. Implement section.
4. Test desktop and mobile.
5. Review with project owner.
6. Refine until approved.
7. Update documentation.
8. Commit approved work.
9. Continue to next section.

Do not implement future sections prematurely.
